# 미션 외관세척기 — HMI + 통신 미들웨어

이 저장소는 미션(변속기 추정) 외관 초고압수 세척설비의 **HMI 화면**과 **PLC-HMI 통신 미들웨어**를 개발하는 프로젝트다.
PLC 자체(시퀀스 로직·안전인터록)는 외주 제작이며 이 저장소의 범위가 아니다.

먼저 읽을 문서: **`PROJECT_PLAN.md`** (전체 개발 로드맵, 폴더 구조 설계 근거, 단계별 완료 조건)

## 폴더 구조 한눈에 보기
- `docs/` — 기획 근거 문서 (설비개요, I/O 태그맵, 공정시퀀스, 미확정 확인사항 체크리스트)
- `server/` — Node.js 통신 미들웨어 (Modbus TCP로 PLC와 통신, HMI에는 WebSocket으로 상태 전달)
- `simulator/` — 실제 PLC 없이 개발하기 위한 가상 Modbus TCP 서버
- `hmi/` — 산업용PC에 띄울 HTML/JS 화면
- `logs/` — 런타임 로그 (알람이력, 사이클카운트)

## 시작하는 법 (개발 착수 시)
1. `docs/04_확인필요사항.md` 체크리스트 확인 — 통신방식 등 아직 안 정해진 항목이 있으면 먼저 정리
2. `simulator/`부터 개발 착수 가능 (PLC 없이도 진행 가능, PROJECT_PLAN.md Phase 1)
3. 이후 `server/` → `hmi/` 순서로 진행 (Phase 2~4)

## 안전 설계 원칙 (반드시 지킬 것)
이 소프트웨어는 안전 판단(도어 잠금 확인, 비상정지 등)을 하지 않는다. 그 역할은 PLC/하드와이어드가 전담하며, 이 프로그램은 **상태 표시와 지령 전달만** 담당한다. 자세한 내용은 `PROJECT_PLAN.md` §5 참고.
