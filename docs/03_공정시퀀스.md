# 03. 공정 시퀀스 (0~9단계) — 상태머신 설계 근거

- 출처: `세척기_제어시스템_기획_20260826.md` 3항 (초안 — 사용자 확인 대기 상태였음)
- 이 문서는 `server/src/sequence/stateMachine.js`가 "지금 몇 단계인지"를 HMI에 표시하기 위해 참조하는 근거다.
- **중요**: 이 상태머신은 다음 단계로 "진행시키는" 주체가 아니다. 실제 진행 판단과 안전 인터록은 PLC가 담당하고, 여기서는 PLC가 이미 만들어 놓은 레지스터 값을 읽어 미러링만 한다 (기획서 5항 원칙).

| 단계 | 내용 | 관련 신호 (초안) |
|---|---|---|
| 0. 대기 | 시스템 대기 | - |
| 1. 파렛트 로딩 | 작업자가 미션 안착 후 "안착확인" 버튼 누름 | 입력: 안착확인 버튼 |
| 2. 위치이동 | 위치이동 실린더 전진 | 출력: 위치이동실린더 전진 솔레노이드 / 입력: 전진완료 근접센서 |
| 3. 리프트 업 | 리프트 실린더 상승 | 출력: 리프트실린더 상승 솔레노이드 / 입력: 상승완료 센서 |
| 4. 안전 확인 | 안전도어 닫힘·잠김 확인 (PLC 자체 판단, 통신 경유 안 함) | 입력: 도어 인터록 스위치 |
| 5. 세척 | 파렛트 회전 시작(인버터 속도지령) + 노즐 X·Z축 세척 궤적 이동 + 고압펌프 On | 출력: 인버터 속도지령, 노즐 서보 X/Z 지령, 고압펌프 On |
| 6. 세척 종료 | 설정시간 경과 또는 궤적 종료 → 펌프 Off → 회전 정지 → 노즐 원점 복귀 | - (설정시간 초기값: 1대당 약 10분, 시운전 후 세척력 보고 조정 예정 — 2026-08-31 확인, `docs/04_확인필요사항.md` 참고) |
| 7. 리프트 다운 | 리프트 실린더 하강 | 출력: 리프트실린더 하강 솔레노이드 / 입력: 하강완료 센서 |
| 8. 위치 복귀 | 위치이동 실린더 후진 | 출력: 위치이동실린더 후진 솔레노이드 / 입력: 후진완료 근접센서 |
| 9. 완료 | 반출 가능 알림 | 출력: 완료램프/부저 |

**공통(전 구간)**: 비상정지 시 즉시 전체 정지(PLC/하드와이어드), 도어 열림 감지 시 고압펌프·노즐·회전 즉시 정지. 고압펌프 압력/유량 이상 감지 시에도 PLC가 운전을 정지시킨다 (2026-08-31 확인). 이 조건들은 `hmi/js/screens/mainScreen.js` 또는 `alarmScreen.js`에서 "표시"로만 반영하고, 정지 자체는 PLC/하드와이어드가 수행한다.

## 상태머신 구현 메모
- 각 단계 번호(0~9)를 레지스터 1개로 PLC가 발행한다고 가정 (통신방식 확정 전까지 임시 가정 — 확정되면 이 문서와 `02_IO_태그맵.md`에 반영)
- `stateMachine.js`는 이 값을 폴링/구독하여 `hmi`에 WebSocket으로 push
- 시뮬레이터(`simulator/src/mockPlcServer.js`)는 테스트를 위해 이 0~9 값을 일정 주기로 순환시키거나, 테스트 스크립트가 임의로 지정할 수 있게 만든다
