## 2026-09-03 PLC 발주사양서(`docs/08_PLC_발주사양서.md`) 정리 중 도출된 항목

기존 문서(01~06)와 `registerMap.js`를 발주 사양서 형태로 재정리하는 과정에서, 시퀀스 전이조건·핸드셰이크 규칙·레지스터 스케일에 **정의되지 않은 공백**이 드러났다. 아래는 전부 PLC업체 회신이 필요한 항목이며, `docs/08` §7-2와 1:1로 대응한다. 답이 오면 이 문서와 `docs/08`, 필요 시 `docs/02_IO_태그맵.md`를 함께 갱신한다.

- [ ] ① 자동 사이클 시작 트리거 — `DI 10001` 안착확인 버튼인지, `Coil 00007` HMI 시작 지령인지, 둘 다(AND)인지 (`docs/03` 1단계에 정의 없음)
- [ ] ② 실링 완료 판정 방법 — 별도 완료센서가 없어 4단계 전이조건이 미정 (타이머? 압력스위치 신설?)
- [ ] ③ 세척시간 설정 레지스터 필요 여부 — **현재 태그맵에 없음.** 초기값 10분은 시운전 후 조정 대상인데 HMI에서 조정하려면 HR 태그 신설 필요
- [ ] ④ 노즐 원점복귀 지령/완료 태그 필요 여부 — **현재 태그맵에 없어** 6단계 원점복귀를 PLC 내부 처리로 가정 중
- [ ] ⑤ 완료램프/부저(`Coil 00006`) 해제 조건과 도어 열림(`Coil 00012`) 지령 주체 (PLC 자동 / HMI 수동 / 작업자 버튼)
- [ ] ⑥ 경로점 ack(`DI 10021`) 클리어 주체와 타임아웃 — 당사 `vehicleModelRecipe.js`는 100ms 폴링·5초 타임아웃을 가정 중
- [ ] ⑦ `Coil 00007/00008` 오토사이클 시작·정지가 펄스(엣지)인지 레벨 유지인지 — **현재 `wsServer.js`는 1만 쓰고 0으로 내리지 않는다.** PLC가 엣지 검출로 처리하면 두 번째 사이클이 시작되지 않으므로, 확정되면 미들웨어 코드 조정 필요
- [ ] ⑧ 실린더 더블/싱글 솔레노이드 여부 + 상반 코일 쌍(전진/후진 등) 배타 처리 방식 — 싱글이면 코일 2개를 1개로 통합하고 태그맵 축소 필요
- [ ] ⑨ 통신 두절 감지용 워치독 레지스터 필요 여부 — **현재 태그맵에 없음.** 미들웨어는 연결이 끊기면 재접속만 시도할 뿐 정지 지령을 보낼 수 없으므로, PLC가 자체 폴백을 보장하지 못하면 워치독 태그 신설 필요
- [ ] ⑩ 토크·전류 레지스터(`HR 40007`~`40012`) 실제 스케일 — `0.01N·m`/`0.01A`는 제안값
- [ ] ⑪ 위치 레지스터 스케일(`0.1mm/count` 제안값) 확정 + 음수 좌표 사용 여부(부호 있는 16bit인지)
- [ ] ⑫ PLC IP 주소, TCP 포트(502 제안), Unit ID(1 제안), 허용 폴링 주기 — `plcConfig.js`의 `pollingIntervalMs`는 여전히 `null`(개발 기본값 300ms)

> ⑦⑨는 답변에 따라 코드 수정이 따라오는 항목이다. 그전까지는 현재 구현을 그대로 둔다 (임의 변경 금지 — `CLAUDE.md`).

## 2026-09-03 PLC 자체제작 검토(`docs/09_PLC_자체제작_검토.md`) 중 도출된 항목

PLC를 외주가 아니라 직접 제작할 수 있는지 검토하면서, **기종 선정과 자체제작 여부 판단에 필요한데 아직 정해지지 않은 값**들이 드러났다. 아래는 `docs/09` §7과 1:1로 대응한다. 앞 절(발주사양서 정리)의 ①~⑫와 중복되는 항목(인버터 프로토콜, 토크·전류 스케일 등)은 여기에 다시 쓰지 않는다.

- [ ] Ⓐ 기종당 경로점(웨이포인트) 상한 — `20기종 × N점 × 2워드(X,Z)`가 PLC 래치(비휘발성) 영역에 들어가야 하는데, **N이 미정이라 필요 용량을 산정할 수 없고 → 기종 선정이 불가**하다
- [ ] Ⓑ 토크·전류(`HR 40007`~`40012`)를 실제로 취득할 수 있는지 — 서보는 PLC와 **펄스열 단방향** 연결(`docs/04` 기확정)이라 드라이브의 토크·전류가 PLC로 자동으로 올라오지 않는다. 드라이브 아날로그 모니터 출력을 받거나 별도 통신을 추가해야 할 수 있음 → **아날로그 입력 모듈 추가 여부가 기종 선정·비용에 영향.** 외주로 가더라도 확인 필요한 항목
- [ ] Ⓒ 안전회로를 어디까지 하드와이어드로 구성할 것인가 — 안전릴레이 사용 여부, 세이프티 PLC 검토 여부 (자체제작 시 실질 난이도·비용을 좌우)
- [ ] Ⓓ PLC 판넬 제작·배선 인력이 내부에 있는가 (또는 판넬만 별도 외주 가능한가) — 로직은 자체, 배선은 외주 같은 분업 가능성 판단용
- [ ] Ⓔ 설비 인수 후 유지보수 담당자가 익숙한 PLC 브랜드 — 실무에서는 사양보다 이게 선정을 좌우할 수 있음
- [ ] Ⓕ 기종별 견적 및 납기 (미쓰비시 / LS일렉트릭 / 지멘스) — Ⓐ~Ⓔ 정리 후 요청
- [ ] Ⓖ 외주 업체 계약에 **PLC 소스 제공 조건**이 포함되는가 (외주 유지 시) — 소스를 못 받으면 장기 유지보수가 업체에 종속됨

> Ⓑ는 자체제작 여부와 무관하게 확인해야 하는 항목이다 — HMI 수동화면의 토크·전류 표시가 여기에 달려 있다.
