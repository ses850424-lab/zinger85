## 답변 기록란

**2026-08-31 답변 수렴**

| 항목 | 답변 |
|---|---|
| 노즐 X축 서보 사양 | 리드 5mm, 스트로크 800mm, 최대속도 25mm/s |
| 위치이동실린더 후진완료 센서 유무 | 존재함 — 전진/후진 각 1개씩 근접센서 |
| 리프트실린더 상승/하강완료 센서 종류 | 근접센서 |
| 노즐 X·Z축 원점·리미트 센서 구성 | 리밋(리미트) 스위치로 추정 — **축당 정확한 개수/구성(원점 1개인지, +/- 리미트가 별도인지)은 아직 미정.** `docs/02_IO_태그맵.md`에는 임시로 축당 1비트만 배치해뒀고, 구성 확정되면 조정 필요 |
| 서보앰프-PLC 통신방식 | 펄스열 — PLC가 직접 펄스를 생성하므로, 미들웨어는 목표위치 값만 PLC에 넘기면 됨 |
| 인버터-PLC 통신방식 | "통신" (아날로그 아님) — **구체 프로토콜(Modbus RTU 등)은 아직 미정.** 다만 PLC가 내부에서 변환을 담당하므로 미들웨어의 레지스터 설계에는 영향 없음 (속도값 하나를 레지스터에 쓰는 건 동일) |
| 안전도어 설계 | 에어실린더 온오프 방식 + 근접센서(닫힘확인) + 도어 닫히면 고무호스로 에어 투입해 실링. 별도의 "실링완료" 센서는 언급되지 않아 추가하지 않음 |
| 세척 사이클 시간 | 초기값 1대당 약 10분 — 시운전 후 세척력 보고 조정 예정 (레지스터화 대상 아님, 참고 메모) |

이 답변을 근거로 `docs/01_설비개요.md`, `docs/02_IO_태그맵.md`, `docs/03_공정시퀀스.md`를 갱신하고 Phase 2(레지스터 매핑 & 어댑터 구현)에 들어간다. 위 굵은 글씨로 표시한 미정 항목(원점/리미트 축당 구성, 인버터 세부 프로토콜, 고압펌프 이상신호 존재 여부)은 여전히 확인 대기 중.

**2026-08-31 태그맵 리싱크**

사용자가 `docs/02_IO_태그맵.md`를 전통적 Modbus 오프셋 표기(DI 1xxxx/Coil 0xxxx/HR 4xxxx)로 다시 정리하면서 아래 아키텍처를 확정: **HMI/미들웨어는 PLC하고만 Modbus TCP로 통신**하며, PLC-서보드라이버/인버터 간 내부 프로토콜(펄스열, 통신 등)은 PLC업체 구현 범위라 이 프로젝트와 무관. 이 과정에서 문서에 빠졌던 이전 확인 항목(회전감지센서, 서보 이동완료, 고압펌프 압력/유량이상 분리, 파렛트회전 운전상태, 오토사이클 시작/정지, 운전모드전환)은 삭제가 아니라 **병합**임을 확인 — `docs/02_IO_태그맵.md`에 반영 완료. 서보 위치제어 핸드셰이크도 "목표위치+이동시작 코일→이동완료"에서 "위치지령 HR + 현재위치 피드백 HR"로 단순화됨.
