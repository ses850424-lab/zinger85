# 01. 설비 개요

- 출처: `세척기_제어시스템_기획_20260826.md` 1~2항 (작성일 2026-08-26)

## 설비 설명
1000bar 초고압수로 미션(변속기 추정) 외관을 세척하는 설비. 파렛트에 미션을 안착시켜 세척 위치로 이동·상승시킨 뒤, 파렛트를 회전시키면서 2축 서보로 움직이는 노즐에서 고압수를 분사해 세척한다.

**아키텍처 확정 (2026-08-31)**: HMI/미들웨어는 **PLC하고만 Modbus TCP로 통신**한다. PLC가 서보드라이버·인버터와 내부적으로 어떤 프로토콜을 쓰는지(펄스열, 아날로그, 통신 등)는 PLC업체 구현 세부사항이며 이 프로젝트 범위 밖 — 자세한 내용은 `docs/02_IO_태그맵.md` 참고.

## 역할 분담
| 구분 | 담당 |
|---|---|
| 기계설비 | 사용자 직접 제작 |
| PLC (시퀀스 로직 + 안전인터록 + 서보/인버터 지령) | 외주 제작 |
| HMI 화면(산업용PC + HTML/JS) + 통신 미들웨어(Node.js, Modbus TCP) | Claude와 공동 제작 — 본 프로젝트의 범위 |

## 액추가이터 구성 (2026-08-26 대화로 확정)
| 구분 | 구동방식 | 비고 |
|---|---|---|
| 파렛트 위치이동 | 에어실린더 (전진/후진) | 파렛트를 세척 위치로 수평 이동 |
| 파렛트 리프트 업/다운 | 에어실린더 (모터 아님 — 이전 검토 정정) | 파렛트를 세척 위치까지 승강 |
| 노즐 X축 (직선평면이동) | 서보모터 | 리드 5mm, 스트로크 800mm, 최대속도 25mm/s (2026-08-31 확인) — PLC와는 펄스열 방식으로 통신. 원점/리미트 센서: 최대리밋 1개 + 최소리밋 1개 + 회전감지센서 1개, 총 3개 (2026-08-31 확인) |
| 노즐 Z축 (수직이동) | 서보모터 1대 + 볼스크류 2개 + 감속기(10:1) + 라인샤프트 | 이송질량 70kg, 리드 5mm, 최대속도 25mm/s, 축간거리 1000mm, 모터선정 기준토크(SF1.5) 약 0.1197N·m(Case1, 가감속0.1s)~0.1095N·m(Case3, 0.5s), 모터 3000rpm — 500W는 과대선정, 50~100W급 검토 권장 (근거: `볼스크류2축_서보모터선정_계산서.xlsx`). PLC와는 X축과 동일하게 펄스열 방식으로 통신 (2026-08-31 확인). 원점/리미트 센서 구성은 X축과 동일 — 최대리밋 1개 + 최소리밋 1개 + 회전감지센서 1개, 총 3개 |
| 파렛트 회전 | AC모터 + 인버터(VFD) | 속도가변 — HMI 화면에서 속도 조절 가능해야 함. 고정값 없음 — 대략 5초/회전 = 12rpm 부근에서 시작 예상 (확정값 아님). PLC-인버터 간은 아날로그가 아닌 "통신" 방식으로 확인(2026-08-31) — 구체 프로토콜(Modbus RTU 등)은 사용자가 추후 확인 예정, 미들웨어는 속도값만 레지스터에 전달하면 되므로 이 미확정이 개발을 막지 않음 |
| 고압펌프 | On/Off만, 압력조절 기능 없음 | 이상신호 존재 — 압력센서·유량센서로 이상여부 판단, 압력게이지 이상 시 PLC가 운전을 정지시킨다 (2026-08-31 확인, PLC/하드와이어드 판단, 이 프로그램은 상태 표시만) |
| 안전도어 | 에어실린더 (온오프 방식) | 근접센서로 닫힘 확인 + 도어가 닫히면 고무호스로 에어를 투입해 실링 (2026-08-31 확인). 별도의 "실링완료" 확인센서는 언급되지 않음 |
| 노즐회전실린더 | 에어실린더 (전진/후진) | 2026-08-31 신규 추가 확인 — 전진 시 노즐 90도 틸팅, 후진 시 원위치 복귀 |

세척 사이클 목표시간(초기값, 2026-08-31 확인): 1대당 약 10분 — 시운전 후 세척력을 보고 조정 예정인 튜닝 대상값이며 고정 사양이 아니다.

이 표는 `server/src/io/motor/`, `server/src/io/cylinder/` 어댑터 코드가 다룰 대상의 원본 근거다. 값이 바뀌면 이 문서와 `PROJECT_PLAN.md` §2를 함께 갱신한다.
